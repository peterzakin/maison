# Support

Thanks for using Maison! If you need help, here's how to get it.

## Getting help

- **Open a GitHub issue:** https://github.com/peterzakin/maison/issues
- Search [existing issues](https://github.com/peterzakin/maison/issues) first — your question may already be answered.

## What to include

To help us resolve your issue quickly, please include:

- A clear description of the problem and what you expected to happen.
- Steps to reproduce, including the command you ran.
- Your Python version (`python --version`) and Maison version.
- Relevant error messages or logs (with any secrets like API keys redacted).
- Your operating system.

For general usage questions, see the [README](README.md).
